# 多篇文献研究

在完整阅读器顶栏点击「研究」，按标题、作者或年份搜索。可在不同搜索中累积勾选最多 20 篇文献；每次最多显示 12 个候选。封面按钮打开逐页预览，原来正在阅读的论文保持原位置。

「系统选择器」使用 OpenAI 扩展表单：资源多选、封面缩略图、展开预览、研究目标建议和自由输入。不支持扩展表单的宿主可继续使用面板内的复选列表。选择结果只接受本轮提供的 Zotero URI，不接受任意本地文件路径。

## 使用流程

1. 勾选论文，选择「比较研究方法与实验结果」「撰写文献综述」「梳理研究脉络与研究空白」，或输入自己的目标。
2. 按需要保留「结合我的高亮与评论」，点击「用于研究」。文献引用、目标和批注偏好进入当前对话上下文，阅读器继续保持 fullscreen。
3. 在原生对话框提出具体问题。例如：“比较这些论文的核心假设和实验设计，结合我的评论列出三条可验证的研究空白。”

选择和预览不会启动 OCR，也不会自动发送问题。模型先查询所选论文的状态；任务确实需要全文时，才在全局允许的情况下发起缺失论文的批量识别。也可点击「识别所选」，明确请求上传这些论文。未配置 MinerU key 时，设置中填写密钥。

## 读取高亮与评论

原有 `list_annotations` 提供按页、标签、颜色筛选的摘要；`research_annotations` 提供完整高亮原文和评论，按字符分页，返回版本、偏移和下一页位置。长评论不再受摘要的 600 字符截断限制。版本变化时须从头读取，避免拼接修改前后的文本。

结果包含批注 key、原 PDF 页序、页码标签、类型、颜色、标签、原文和评论，并附定位链接。尚未完成的本地写入带状态，Zotero 离线时注明缓存。模型需要区分论文证据、用户评论和自己的推论。独立 Zotero 笔记仍通过 `read_notes` 读取。

当前阅读上下文只发布批注条数、评论条数及版本变化，不自动发送所有评论正文。研究文献集合也只提供引用与读取策略。

## 模型工具

| 工具 | 行为 |
| --- | --- |
| `research_choose` | 原生多选论文与研究目标；取消不产生选择，缺少能力时返回候选列表 |
| `research_status` | 返回所选论文的 docId、OCR 状态、全文版本、批注/评论条数，不改变活动阅读页 |
| `research_annotations` | 读取单篇完整高亮与评论，支持 offset/maxChars/version |
| `research_ocr_start` | 对所选论文建立批量任务；默认遵守全局模型 OCR 开关；userRequested 仅用于明确上传请求 |
| `research_ocr_status` | 查询批次和逐篇状态。complete 表示全部任务已结束，不能据此认定每篇识别成功 |
| `research_ocr_cancel` | 取消指定批次；未开始的任务停止，有其他批次正在使用的识别任务继续运行 |
| `paper_full_text` | 通过 docId 分页读取已完成的全文；保持版本校验与当前对话内复用 |

批量任务最多同时处理两篇。已有完整结果不重复识别，活动任务复用；单篇失败不阻止其他文献完成。重新请求失败论文可重试。取消无法撤回已上传的远端文件；提交完整结果前中止仍保留旧缓存。

## 范围与验证

文献集合跟随当前 App 的 model context 恢复和移除，不将其他对话标记为“已经读过”。后台解析和独立预览不注册新的主阅读面板，也不切换活动标签。

无本机 PDF、多个 PDF 附件未明确选择、文件无法读取等错误会按篇显示，不能把失败论文当作已经读到。预览是低分辨率页面，不等于全文分析。当前只从本机 Zotero API 读取，不访问 Zotero SQLite。

`test/research.test.mjs` 验证并发、复用、权限、取消、长评论和背景文档身份；`test/research-form.test.mjs` 通过真实 MCP 内存传输验证表单 schema、缩略图、预览、目标建议、取消和非法资源；`test/research-preflight.mjs` 使用隔离文库与模拟 MinerU 完成两篇研究流程，不上传真实论文。
