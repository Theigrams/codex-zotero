# 使用指南

阅读器有两半：右边的面板用来读和标注，左边的 Codex 对话用来问和讨论。面板会把你在读哪篇、第几页、选中了什么同步给 Codex，所以对话里说"这段""这个公式""这里"，它都知道指的是什么。

## 1. 打开论文

- **在对话里说**："打开 Zotero 阅读器"，或者直接"打开那篇关于五轴奇异点的论文"。Codex 会搜索你的 Zotero 文库并打开。
- **在首页搜**：面板标签栏右侧的 ＋ 打开首页，按标题、作者、年份搜索，回车打开；下面列着最近在读的论文，点一下回到上次的位置。
- **标签页**：每篇论文、每篇笔记各占一个标签。⌘1–⌘8 切到第 n 个标签，⌘9 切到最后一个，⌘W 关闭当前标签。关掉面板再打开，标签和每篇的阅读位置（页码、页内位置、缩放）都会恢复。
- 同一时间只有一个面板在工作：Codex 每次打开阅读器都会新建面板，旧面板会显示"阅读器已在新的面板中打开"并停止响应。

## 2. 阅读

| 操作 | 方法 |
|---|---|
| 缩放 | 触控板捏合，或 = / -；0 回到适应宽度 |
| 裁边 / 原始页面 | C（默认裁掉白边，保留页眉页码） |
| 跳页 | G，输入页码回车；或点顶栏的页码 |
| 查找 | ⌘F，回车 / ⇧回车 在结果间跳转，Esc 关闭 |
| 论文内链接 | 点"式 (11)""图 7""[12]"跳过去，跳转处会闪一下框；鼠标停在链接上会预览目标处 |
| 返回 / 前进 | ⌥← / ⌥→，或点顶栏的"↩ 第 n 页" |

往下读时顶栏会自动收起，往上滚一点就出来。渲染方式（像素对齐 / 0.5 档）在设置里切换。

## 3. 选择与提问

| 选择 | 方法 |
|---|---|
| 一个词 | 双击 |
| 一整句 | 三击（可跨行、跨栏，跳过页眉和图注） |
| 任意一段 | 拖选 |
| 公式或图 | 按住 ⌥ 拖出一个框 |

选中后出现工具条：

- **提问**：就地输入问题，回车。问题连同选段文字和原图截图一起发到对话里；公式以截图为准。
- **高亮**：用第一种颜色高亮（同 H）。
- **评论**：高亮并直接打开评论框。

也可以不点按钮，选中后直接在对话框里打字，比如"这段在说什么"。复制用 ⌘C。

## 4. 批注

批注直接写进 Zotero，在 Zotero 自己的阅读器里也看得到。

- **高亮与下划线**：选中后按 H 或 1–9（对应设置里的颜色与标签），加 ⇧ 为下划线。每种颜色带一个标签，比如默认的"重点""问答""定义""启发""存疑"。
- **编辑**：点一条批注弹出小窗：换颜色（点色块或按数字键）、写评论、删除（⌫）。评论支持基础 Markdown（**粗体**、*斜体*、`代码`、列表、链接）和 `$…$`、`$$…$$` 公式。
- **撤销删除**：⌘Z 恢复刚删除的批注。
- **批注抽屉**：A 打开，按阅读顺序列出本篇所有批注，可以按标签筛选，点一条跳过去。
- **第一次写入**时 Zotero 会弹窗请求授权，选"始终允许"。Zotero 没开时，批注先画在面板上，写入排队，等 Zotero 开了自动补写；写入失败的只在抽屉里提示，可以重试。

## 5. 和 Codex 一起读

**问一处的意思。**选中后提问，或在对话里说"这个公式里 γ 是什么"。Codex 回答后，会把这次问答简短地存成该处的批注（"问答"那种颜色，带 `AI问答` 标签，问答旁有个小圆点）。同一处再问：相近的问题替换答案，不同的问题追加。

**让 Codex 帮你标。**比如：

- "把摘要中的核心句子高亮出来"
- "把这一节里所有的假设标成存疑"
- "删掉刚才那条批注"

**让 Codex 指给你看。**"作者在哪里定义了 ATOA？""实验参数在哪一页？"面板会滚到原文那里并闪一下。

**公式看不清不用框选。**提取出的公式文字可能乱码；Codex 需要时会自己取原版图像看（按公式编号、原文或整页），不会请你去框选。

**跨论文找。**"我之前在哪篇论文里标过关于样条平滑的内容？"Codex 会搜索你整个文库的批注和评论，告诉你出处和页码。

**增强识别（可选，默认关闭）。**点顶栏的识别图标（✦），这篇论文就交给 MinerU 识别（20 页约半分钟）；第一次会在图标下请你填 MinerU 的 Key，检查有效后存入钥匙串。用自部署的 MinerU，就在设置 → 增强识别里填它的地址与 Key，"测试连接"可检查是否连得上。识别后 Codex 读到的公式是 LaTeX、表格按行列、双栏按阅读顺序，论文地图也用识别后的文字生成。打开总开关，则每篇打开的论文都自动识别。论文要上传到 MinerU（官方服务会消耗你的额度）；结果存在本机，每篇只识别一次。图标：灰色 ✦ 未识别，沙漏识别中，蓝色 ✦ 已生效，红色警告失败（悬停看原因，点一下重试）。识别后，从地图或论文内链接跳到公式、图、表，闪框是 MinerU 识别出的整块（图连同全部子图和图注）。想检查 MinerU 分得对不对，按 ⇧M 进入调试模式：页面上画出全部分块，按阅读顺序编号；点一块复制它的内容（文字、公式 LaTeX、表格 Markdown、图片），再按 ⇧M 退出。

**跨论文读。**"比较一下这篇和那篇奇异规避论文的方法"：Codex 可以直接读文库里另一篇论文，在后台打开，不开标签，你面前的论文不变。

## 6. 笔记

- **在面板里读 Zotero 笔记**：批注抽屉（A）顶部的"笔记"区列出这篇论文的子笔记，点一篇在新标签打开。公式、表格、图片都能显示；A 打开目录。
- **从笔记跳回论文**：笔记里引用的高亮、地图里的页码和"式 (N)""图 N"都可以点，跳到论文对应处；顶栏"↩ 回到笔记"返回。
- Codex 也能读你的笔记（"看看我对这篇的笔记里怎么说的"），但笔记不能在面板里编辑，请在 Zotero 里改。

## 7. 论文地图

一份带页码的导航笔记：一句话概括、问题与贡献、结构、核心概念与符号、方法要点、主要结果、假设与局限。Codex 回答问题前先看地图，知道该去读哪几页，不必每次重读全文。

- **生成**：在批注抽屉顶部的"笔记"区点"生成论文地图"（只在还没有地图时出现），或在对话里说"生成这篇的论文地图"。由 Codex CLI 调用模型通读全文，通常一两分钟，不打断阅读。
- **存放**：Zotero 子笔记"论文地图：标题"，标签 `论文地图`；首行写明由哪个模型、何时生成，状态"未核验"。
- **重新生成**：在对话里说。抽屉里不放重新生成的按钮，免得误点。
- **设置**：模型、推理强度（低 / 中 / 高）和提示词都可以改。

生成地图会把论文全文发给模型，只在你要求时进行。

## 8. 导读与精读笔记

想把一篇论文读透时，对 Codex 说**"带我读这篇"**。

- Codex 会先读一组**精读问题**（研究问题与价值、关键人物与实验室、已有研究的不足、作者的思考路径、核心直觉、具体方法、数学推导、实验如何验证、Take-aways，最后是批判与延伸），再带着这些问题引导你。
- 背景信息它直接讲；到关键处，它会先让你想："如果是你，会怎么解决？"然后一起排除走不通的办法，一步步接近作者的思路，再试着往前推一步。
- **每次只讲一点、只问一个问题**。你可以随时说"直接告诉我""给个提示""跳过""先到这"。
- 每读完一个问题，它会把结论记进这篇论文的**精读笔记**（Zotero 子笔记"精读笔记：标题"），回复末尾只多一行"（已记入笔记）"。笔记按读下来的思路组织，末尾有阅读进度：哪些问题读完了，哪些还没读到。
- **下次接着读**：新开一个对话，说"继续带我读这篇"，它会回顾上次读到哪里，从下一个问题接着来。所有问题读完，这篇就读完了。
- 不开导读时，Codex 只回答你问的，不会主动往下带。平时的讨论想留下来，说"把我们的讨论整理成笔记"。
- 精读问题在设置里可以改成你自己的。

## 9. 设置（⌘,）

| 一节 | 内容 |
|---|---|
| 渲染方式 | 像素对齐 + 近灰加深（默认）/ 0.5 档渲染 |
| 批注颜色与标签 | 增删、改名、换色；按键 1–9 依次对应；标签叫「问答」的那一行是问答批注的颜色 |
| 快捷键 | 点一项后按新的组合键；冲突时两者互换 |
| 论文地图 | 模型、推理强度、提示词 |
| 精读问题 | 导读用的问题清单 |

每一节都可以恢复默认。

## 11. 常见问题

- **面板显示"无法连接 Zotero"**：打开 Zotero，并确认设置 → 高级里已允许其他应用程序与 Zotero 通信。
- **公式显示不对**：字体装好后要 ⌘Q 重启 Codex，见 [INSTALL.md](../INSTALL.md)。
- **选中的文字里连字、符号是乱码**：PyMuPDF 或 fontTools 没装或没找到，见 INSTALL.md 第 1 步。
- **面板变成"阅读器已在新的面板中打开"**：Codex 又打开了一个阅读器面板，用新的那个即可。
- **在 Zotero 里改了批注**：面板几秒内会自动刷新。
